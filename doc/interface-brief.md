# 《邻里互助》Game Interface Brief

## Product frame

- 玩家：能读中文或英文、熟悉手机聊天与公告列表的普通用户。
- 核心交互：从共享公告中选一件小事，领取/携带/交接一个具体物品，并阅读连续故事结果。
- 情绪承诺：小事被认真对待，别人的行动真实存在，但不会把玩家拖进复杂制度。
- 主要状态：开场节拍、正常叙事、公告浏览、提交中、成功、竞争冲突、离线/重连、关系笔记、收据待确认。
- 目标尺寸：390×844 主验收，320×568 紧凑验收；触屏优先，键盘完整可用。

## Promise horizons

- 首个动作：领取备用雨伞委托。
- 首局：把雨伞送达、交给别人或发现它已被别人领取。
- 前 10 分钟：认识一名居民，完成一次公共状态变化，看到一次私人关系反馈。
- 单次停止：完成或交接一个委托。
- 长期承诺：共享社区不断变化，个人关系在自己的故事里延续。

## Screen and state inventory

- 主故事页：状态 HUD、地点/时间、工具图标、累积正文、场景图、叙事化数值变化、选择栏。
- 共享公告页：开放/已领取/交接中/完成的委托，物品可用性，最近公共变化。
- 关系笔记：只显示已在可见正文中登场的人物与个人关系事件。
- 冲突恢复：生活化原因、最新状态、保留原意或新选择、同 ID 重试入口。
- 离线/重连：本地可读存档、待处理动作、游标补拉进度；绝不伪装成已提交。

## Environment

- 平台内为主构图，不为外部访客栏永久下移 UI。
- 游戏自有共享世界服务挂载在当前 session UUID 的 `/api/*` 下。
- Pages 仅是静态镜像，不宣称为可写共享世界。
- 生产环境没有明确 `?local=1` 时不得静默退回本地模拟。

## Content and assets

- 双语文案全部走 i18n。
- 场景资产：地域中性的共享大厅、包裹架、楼梯间、街角店、小花园、公交站和住户门口。
- 重要对话资产由提交后的稳定事件 ID 幂等生成；图内禁止任何文字。
- SVG 图标统一线宽与视重；关系使用无文字笔记本图标。

## Direction inputs

- 用户明确要求通俗易懂，排除金融概念与高概念命名。
- 产品面向国际用户；中文/英文只改变界面语言，不决定人物族裔、建筑国家或公共空间形态。
- 本实验重点不是内容规模，而是验证多人竞争、交接、游标重连、收据恰好一次和私人关系隔离。
- 视觉与交互必须让普通用户先理解“谁在做哪件小事”，技术状态只在错误详情中出现。
