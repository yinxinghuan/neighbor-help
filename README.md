# Neighborly Help / 邻里互助

An asynchronous shared-world role-playing experiment about small acts of everyday help in a culturally neutral apartment community.

正式运行时由同一 UUID 路径承载前端与共享世界 Worker。GitHub Pages 仅为静态前端镜像，不连接正式共享数据库。

## Development

```bash
npm ci
npm run build
```

See `doc/requirements.md`, `doc/visual.md`, `doc/technical.md`, and `doc/shared-world-contract.md` for the game and authority contracts.
